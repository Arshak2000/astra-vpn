# ASTRA VPN server

This folder contains the first server-side infrastructure step for ASTRA VPN.

## Current status

- The public website is separate from the VPN tunnel.
- `setup-wireguard.sh` installs WireGuard on a **fresh Ubuntu/Debian VPS** and starts an initial server interface.
- It does not create accounts, client profiles, billing, a control panel, or a working CONNECT button.
- Do not advertise the VPN as available until client routing, DNS, firewall rules, authentication, privacy policy, and cross-device tests are complete.

## Before running

A responsible adult who manages the VPS should:
1. Provision a fresh supported Ubuntu VPS and keep its OS updated.
2. Review this script before running it.
3. Ensure console/recovery access is available.
4. Run the script as root: `sudo bash setup-wireguard.sh`.
5. Allow inbound **UDP 51820** in the provider firewall and configure the host firewall without locking out SSH.
6. Keep all private keys on the server. Never commit them to GitHub or send them in chat.

The script refuses to overwrite an existing `/etc/wireguard/wg0.conf`. It creates a server interface at `10.66.0.1/24`, enables IPv4 forwarding, and configures NAT through the detected default network interface.

## Next engineering steps

1. Add a secure control-plane API with authentication and administrator authorization.
2. Create and revoke individual WireGuard peers on the server without exposing the server private key.
3. Store only the minimum account/device metadata; never store client private keys on the website server.
4. Add rate limits, audit events, abuse handling, and a clear privacy policy.
5. Test DNS, IPv4/IPv6 leak behavior, reconnects, revocation, and performance on iOS, Android, Windows, and macOS.

**No client configuration is generated by this initial setup.**
